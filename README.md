# СтройСмета

Telegram-бот для расчёта строительных работ и материалов.

## Возможности
- отдельные объекты для каждого Telegram-пользователя;
- комнаты и автоматический расчёт площади пола, потолка и стен;
- вычитание дверных/оконных проёмов заложено в расчётную модель;
- ручное добавление работ;
- отдельный справочник цен на работы;
- отдельный справочник материалов: упаковка, цена, расход;
- расчёт количества упаковок с запасом;
- итог отдельно по работе и материалам;
- экспорт сметы в Excel и Word;
- SQLite.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# впишите BOT_TOKEN в .env
python main.py
```

Для Windows вместо `source ...` используйте `.venv\\Scripts\\activate`.

Цены в справочниках пользователь задаёт сам. Это сделано специально: прайсы можно менять без изменения кода.
